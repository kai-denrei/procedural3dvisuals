p3dv — embed examples

1. mountFullscreen — one line

We own the renderer and the loop. Pass a canvas, get a running effect.

const fx = await mountFullscreen({ canvas, effect: 'wormhole', basePath: '../' });

2. createTexture — on real geometry

Your scene, your renderer. The effect renders into a texture applied to a rotating box — the portal-on-a-plane / glTF-doorway case.

const portal = await createTexture(renderer, { effect:'corona', size:512, basePath:'../' });
portal.update(t);   // each frame, BEFORE your main render
mesh.material.map = portal.texture;
